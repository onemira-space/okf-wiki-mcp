okf-wiki-mcp

Zero-dependency offline Model Context Protocol (MCP) server & CLI for local Google OKF v0.2 and Obsidian Markdown meeting-notes vaults.

npx github:onemira-space/okf-wiki-mcp --vault ~/Documents/Meetings stats
# or via Homebrew:
brew tap onemira-space/tap https://github.com/onemira-space/homebrew-tap
brew install okf-wiki-mcp

MCP Tools Exposed Over Stdio JSON-RPC 2.0

ToolPurpose
okf_search_meetingsSearch local .md transcripts by keyword, speaker, tag, and date range.
okf_list_action_itemsExtract open or completed - [ ] action items and @owner assignments.
okf_read_noteRead frontmatter, body, and incoming [[wiki-link]] backlinks.
okf_topic_graphBuild relational topic edges and detect unresolved links.
okf_vault_statsAudit total notes, speaker count, frontmatter coverage, and open tasks.
